# 游戏公共功能模块计划

## 1. 账号系统 (Account System)

### 核心功能
- **接口驱动设计**：定义 `IAccountProvider` 接口，包含异步方法
- **双重实现**：
  - `LocalProvider`：使用本地文件存储（加密 JSON）
  - `RemoteProvider`：预留 API 调用模板
- **动态切换器**：`AccountManager` 作为全局入口，根据配置切换 Provider
- **数据迁移**：提供 `SyncToCloud()` 方法，支持本地数据推送到服务器
- **成熟方案**：单例模式 + JWT 结构

### 模块间约束与通讯
- 所有业务逻辑只能通过 `AccountManager` 访问接口
- 严禁直接接触底层实现
- 通过事件系统通知登录状态变化

## 2. 道具系统 (Inventory System)

### 核心功能
- **数据驱动设计**：道具属性配置在外部文件
- **背包管理**：槽位管理、叠加上限、交换位置
- **道具逻辑**：消耗/使用逻辑
- **组合模式**：处理不同类型道具的效果

### 模块间约束与通讯
- 道具数量变化时触发 `OnInventoryChanged` 事件
- UI 模块通过订阅事件自动刷新界面
- 与账号系统集成，道具数据通过 AccountManager 保存

## 实现顺序
1. 创建基础目录结构
2. 实现账号系统接口和本地实现
3. 实现账号系统远程实现和管理器
4. 实现道具系统核心逻辑
5. 实现道具系统与账号系统的集成
6. 编写测试用例
